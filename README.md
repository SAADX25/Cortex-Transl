# Cortex Transl

ترجمة حوار الألعاب على Windows أثناء طور القصة. البرنامج يلتقط الشاشة فقط ولا يحقن اللعبة.

## الاستخدام

1. أدخل مفتاح DeepL.
2. اختر لغة اللعبة.
3. اضغط **تحديد مربع الحوار** (أو `F9`) واسحب حول صندوق الكلام.
4. شغّل اللعبة **Borderless Windowed**.
5. اضغط **ابدأ الترجمة** أو `F8`. الترجمة تظهر فوق الصندوق.

| اختصار | الوظيفة |
| --- | --- |
| `F8` | تشغيل / إيقاف الترجمة التلقائية |
| `F9` | تحديد مربع الحوار |
| `F10` | ترجمة مرة واحدة |

## المتطلبات

- Windows 10 أو Windows 11
- .NET 10
- مفتاح DeepL API

## البناء

```powershell
dotnet restore
dotnet build
dotnet run --project src/CortexTransl.App
```
